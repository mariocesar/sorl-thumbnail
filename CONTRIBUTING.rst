Contributions are welcome. The `contributing
guide <https://sorl-thumbnail.readthedocs.io/en/latest/contributing.html>`__
explains how to run the tests and send a pull request.

It is ok if you used AI to write a change, but say so, run the tests yourself and reply
to the review. Pull requests sent by scripts/bots are closed. See `Using AI
tools <https://sorl-thumbnail.readthedocs.io/en/latest/contributing.html#using-ai-tools>`__.

By contributing you agree to abide by the `Code of
Conduct <CODE_OF_CONDUCT.md>`__. To report a security issue, follow the
`security policy <SECURITY.md>`__ instead of opening a public issue.
